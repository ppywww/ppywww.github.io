### MVP 交付定义（不可扩张）

```
✅ 必交付：首页 / 文章详情 / 归档 / 分类 / 标签 / 搜索 / 深色模式 /

           KaTeX、系列页、访问统计、栏目级配色、子集化字体
```

## 五、变更规则

1. 任何改动 **§一 已锁定项** 的需求，必须由老板明确同意，并在本文件追加新版本记录。
2. Agent 之间出现分歧时，以本文件 §一 为准；本文件未覆盖的，升级给 Lead 裁决。
3. **禁止擅自扩张 MVP 范围**（P-05）。发现新需求 → 写入需求池，不进入当前迭代。
4. **写入纪律**：临时占位符替换必须做「符号全变体清点 + 逐行配对校验」，历史事故：本文件曾出现代码围栏损坏为 `@@`。
