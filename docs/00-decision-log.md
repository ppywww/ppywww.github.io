### MVP 交付定义（不可扩张）

`@
✅ 必交付：首页 / 文章详情 / 归档 / 分类 / 标签 / 搜索 / 深色模式 /
         关于我 / 作品页 / Giscus(默认关) / RSS / SEO / 响应式 /
         阅读时长+TOC / 404 / GitHub Actions 自动部署
❌ 不在 MVP：相关文章、代码复制按钮、灯箱、快捷键、阅读进度条、
           KaTeX、系列页、访问统计、栏目级配色、子集化字体
`@
